About this map

What the index measures

Each facility is one harbor's fuel, ice, hoist/crane or cold storage, where the inventory's current status is "available". The index removes one facility at a time. Any harbor that then has no working facility of that service within the selected sea distance is cut off. The facility's stranded value is the mean annual all-species ex-vessel landed value (2019–2024, nominal dollars) of the harbors it cuts off. The thresholds are 25, 30, 40 (headline) and 50 charted-equivalent nautical miles; the results are stable across that band.

Why values are ranges

About three-quarters of top-10 entries rest on a weak facility record. The main run counts only "available" facilities as working. Sensitivity run s1 also treats every "no source located" cell as available. s1 is a lower bound on stranding, not a plausible state. Values are shown as the range across main and s1. Some harbors report landings only inside a shared agency group (most of Washington, and some Oregon tables). Their value is itself a range: the lower end counts only the harbor's own published value, and the upper end the whole group's value. Only entries marked Holds under both runs stay in the top 10 in both runs; they are stated without the range caveat. Garibaldi is only ever a range ($0–8.2M at 40 nm).

s4 is a labelled sensitivity, not the default. In s4, Point Arena and Port Orford, which offload only by launch hoist and have no moorage, can't use another harbor's hoist.

Unverified facility cells

A targeted verification pass re-checked 42 cells; 40 are still unverified and drive most of the gap between main and s1. "No source located" means no public source was found, not that the service is confirmed absent. Each harbor's panel shows status, confidence, the date of the observation and its source.

Distances are a lower bound

Sea distances are shortest water paths on OpenStreetMap shoreline, with no depth, tide, bar conditions, weather or traffic lanes. They run a median 5.9% shorter than NOAA's Distances Between U.S. Ports; charted-equivalent nm = model nm × 1.06. Several real backups were trucked, not run by boat.

The five validation closures

The closures test whether the index identifies the backup actually used, not the size of stranded value. Ilwaco landings are available only as a Dungeness-crab-only group series. For the Ilwaco review, the failed cell was restored to "available" before removal; this was a review step and does not change the index.

Data sources and dates

  • Facilities: port and harbor sites, agenda packets, the Oregon Coastal Ports Snapshot (2023), operator postings and news. Observations are dated ; current status = the latest dated observation.
  • Landed value: CDFW (Marine Fisheries Data Explorer), ODFW (FTR205 port reports), PacFIN (ALL005, CRAB002) and NOAA Fisheries (FOSS).
  • Distances: NOAA Distances Between U.S. Ports (2025) for validation.
